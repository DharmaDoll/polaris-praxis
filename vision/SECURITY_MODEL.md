# Security Strategy Model

## Eight-Step Model

| Step | Question | Primary Concern |
|---|---|---|
| 1. Asset | 何を守るのか | Asset / Crown Jewel |
| 2. Business | なぜ守るのか | Mission / Business Value |
| 3. Threat | 誰から守るのか | Threat Actor / Intent / Capability / Opportunity |
| 4. Attack Path | どう攻撃されるのか | Attack Chain / Path |
| 5. Risk | 何が起きるのか | Likelihood × Impact |
| 6. Control | どこでどう止めるのか | Prevent / Detect / Respond / Recover |
| 7. Residual Risk | 何が残るのか | Risk Acceptance |
| 8. Resilience | それでも事業を継続できるか | Anticipate / Withstand / Recover / Adapt |

## Asset Value

```text
Asset Value
≈ Intrinsic Value
+ Path / Positional Value
+ Operational Value
```
