# Vision

## Vision Statement

セキュリティを「対策の集合」ではなく、事業価値・脅威・リスク・レジリエンスを一続きで扱う経営・技術システムとして運用する。

## Desired State

組織は以下を説明できる状態を目指す。

- 企業・組織のVision、Values、年間／期目標から、なぜこのSecurity ObjectiveとKPIを選んだのか
- 何を守るのか
- なぜ守るのか
- 誰から守るのか
- どう攻撃され得るのか
- 何が起きるのか
- どこでどう止めるのか
- 何が残るのか
- 侵害されてもどう事業を継続するのか
- 何をいつ改善するのか
- 改善した結果、何がどう変わったのか
- その判断根拠は何だったのか
- 実績とEvidenceから、次期・次年度に何を継続・変更・中止すべきか

## Long-Term Goal

このRepositoryを、組織のCybersecurity Strategy / Risk / Control / Execution / Evidenceをつなぐ中枢として機能させる。

将来的には、以下の関係を機械可読かつ追跡可能にする。

```text
Company / Organization Goal
→ Security Objective
→ Business Service
→ Crown Jewel
→ Threat
→ Attack Path
→ Risk
→ Control
→ Initiative
→ KPI
→ Evidence
→ Actual
→ Decision
→ Next-period Recommendation
```
