# Vision

## Vision Statement

セキュリティを「対策の集合」ではなく、事業価値・脅威・リスク・レジリエンスを一続きで扱う経営・技術システムとして運用する。

## Desired State

組織は以下を説明できる状態を目指す。

- 何を守るのか
- なぜ守るのか
- 誰から守るのか
- どう攻撃され得るのか
- 何が起きるのか
- どこでどう止めるのか
- 何が残るのか
- 侵害されてもどう事業を継続するのか
- 何をいつ改善するのか
- 改善した結果、何がどう変わったのか
- その判断根拠は何だったのか

## Long-Term Goal

このRepositoryを、組織のCybersecurity Strategy / Risk / Control / Execution / Evidenceをつなぐ中枢として機能させる。

将来的には、以下の関係を機械可読かつ追跡可能にする。

```text
Business Service
→ Crown Jewel
→ Threat
→ Attack Path
→ Risk
→ Control
→ Initiative
→ Metric
→ Evidence
→ Decision
```
