# Repository Evolution Roadmap

## Phase 0 — Foundation

Goal: RepositoryをSecurity StrategyのSystem of Recordとして成立させる。

- AGENTS.md
- Vision / Principles / Security Model
- Registers
- Templates
- Branch / PR rules
- Initial context collection

Exit Criteria:
- 基本構造が存在する
- Fact / Unknown / Assumption / Decision / Evidenceを区別できる
- Codexとの初回Interviewが実施可能

## Phase 1 — Current State

- Business context
- Organization
- Asset / Crown Jewel
- Architecture
- Threat
- Risk
- Existing Controls
- Resilience

Exit Criteria:
- Top risksを説明可能
- Critical unknownsが明示されている

## Phase 2 — Threat / Attack Path / Risk

- Threat scenarios
- Attack paths
- Risk register
- Crown Jewel exposure

Exit Criteria:
- 優先RiskがAttack PathとBusiness impactで説明できる

## Phase 3 — Strategy / Target State

- Strategic themes
- Target profile
- Annual objectives
- Priority rationale

## Phase 4 — Roadmap / Initiative / Metrics

- FY plan
- H1 / H2 plan
- Initiative definitions
- KPI / KRI
- Baselines / targets

## Phase 5 — Evidence / Review

- Monthly / quarterly / half-year review
- Decision records
- Residual risk review
- Lessons learned

## Phase 6 — Agentic Automation

- Automated consistency checks
- Traceability validation
- Metric ingestion
- Draft report generation
- Scenario analysis
- Executive presentation generation
