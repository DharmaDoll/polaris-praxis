# Prompt: Executive Security Strategy Presentation

既存のStrategy / Metrics / Evidenceから経営向けプレゼンテーション構成を作る。

## Audience

経営層・事業責任者。

## Story

```text
Business Context
→ Material Cyber Risks
→ Why Now
→ Current Exposure
→ Strategic Priorities
→ Investment / Trade-off
→ Expected Outcomes
→ Residual Risk
→ Decisions Required
```

## Rules

- Tool名やControl名から説明を始めない。
- Technical severityよりBusiness impactを優先する。
- 不確実性を隠さない。
- グラフ化可能な指標を優先する。
- 「何を承認してほしいか」を最後に明示する。
- 詳細技術はAppendixへ。
