# Prompt: Compare Control / Architecture Options

複数ControlまたはArchitecture案を、製品機能ではなくRisk Reductionで比較する。

## Evaluate Each Option

- Risks addressed
- Attack paths interrupted
- Prevent / Detect / Respond / Recover contribution
- Expected residual risk
- Business impact
- Operational burden
- Engineering effort
- Security operations effort
- Cost
- Time to value
- Dependency
- Failure mode
- Lock-in
- Reversibility
- Evidence quality

## Output

- Option matrix
- Recommended option
- Why
- What is intentionally not optimized
- Residual risk
- Decision criteria
- Revisit trigger
