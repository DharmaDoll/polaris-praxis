# Prompt: Build Roadmap

承認済みStrategyから実行可能なRoadmapを作る。

## Structure

```text
Vision
→ 3-Year Target
→ FY Objective
→ H1 / H2 Objective
→ Initiative
→ Milestone
→ Metric
→ Evidence
```

## Rules

- Initiativeは必ずStrategic Objectiveに紐付ける。
- Initiativeは必ずRisk Reduction Hypothesisを持つ。
- 依存関係を明示する。
- H1 / H2に無理に均等配分しない。
- Foundation workとOutcome workを区別する。
- 「導入」「展開」「作成」だけで成功を定義しない。
- Doneの定義をEvidenceで書く。
- 各ObjectiveとInitiativeに、少なくとも1つのKPIを設定する。
- KPIには割合、パーセント、率、比率を使用しない。

## Output

- FY roadmap
- H1 roadmap
- H2 roadmap
- Critical dependencies
- Decision gates
- Expected risk reduction
- Measurement plan
