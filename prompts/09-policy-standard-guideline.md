# Prompt: Create Policy / Standard / Guideline

StrategyからPolicy / Standard / Guidelineへ落とし込む。

## First Decide Document Type

- Policy: 組織として守るべき原則・責任・必須事項
- Standard: 満たすべき具体的要求
- Guideline: 推奨実装・判断支援

## Required Traceability

```text
Business / Risk
→ Strategic Objective
→ Control Objective
→ Requirement
→ Evidence / Verification
```

## Rules

- 根拠のないMustを作らない。
- 例外プロセスを定義する。
- Ownerを定義する。
- 検証可能な要求にする。
- 必要に応じてMUST / SHOULD / MAYを使い分ける。
- 標準と実装例を混同しない。
