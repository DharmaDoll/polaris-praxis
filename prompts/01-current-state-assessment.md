# Prompt: Current State Assessment

現在の組織のセキュリティ状態を、製品一覧やControl一覧ではなく、Business Riskの観点から評価する。

## Analyze

```text
Business
→ Asset
→ Threat
→ Attack Path
→ Risk
→ Existing Control
→ Residual Risk
→ Resilience
```

## Required Output

1. Business criticality summary
2. Crown Jewel candidates
3. High-value positional assets
4. Relevant threat actors / scenarios
5. Critical attack paths
6. Top risks
7. Existing control strengths
8. Control gaps
9. Residual risks
10. Resilience gaps
11. Unknowns blocking confident conclusions
12. Evidence confidence

Do not create a maturity score unless the underlying evidence supports it.
