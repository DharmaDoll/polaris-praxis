# Prompt: H1 / H2 Strategy Review

半期の予実をレビューし、次期計画へ反映する。

## Review Dimensions

- Objectives
- Initiatives
- KPI / Metrics
- Risks
- Attack Paths
- Controls
- Residual Risk
- Incidents / Near Misses
- Business Changes
- Threat Changes
- Assumptions invalidated
- Unknowns resolved / newly discovered

## Required Analysis

For each initiative:

```text
Planned
→ Actual
→ Variance
→ Cause
→ Risk Impact
→ Decision
```

Variance causeは以下で分類する。

- Resource
- Dependency
- Control effectiveness
- Technical complexity
- Organizational adoption
- Business priority change
- Threat change
- Invalid assumption
- Measurement issue

各ObjectiveとInitiativeについて、KPIのBaseline、Target、Actual、Evidence、差異、差異原因を確認する。定性的なKPIは、定義済みの状態判定条件により評価する。実績レビューでも割合、パーセント、率、比率を新たに生成しない。

## Output

- Executive summary
- What improved
- What did not improve
- Material risk changes
- Invalidated assumptions
- Lessons learned
- Continue / Change / Stop decisions
- H2 or next FY recommendations
