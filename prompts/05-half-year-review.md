# Prompt: H1 / H2 Strategy Review

半期の予実をレビューし、次期計画へ反映する。

## Review Dimensions

- Objectives
- Initiatives
- Metrics
- Risks
- Attack Paths
- Controls
- Residual Risk
- Incidents / Near Misses
- Business Changes
- Threat Changes
- Assumptions invalidated
- Unknowns resolved / newly discovered

## Required Analysis

For each initiative:

```text
Planned
→ Actual
→ Variance
→ Cause
→ Risk Impact
→ Decision
```

Variance causeは以下で分類する。

- Resource
- Dependency
- Control effectiveness
- Technical complexity
- Organizational adoption
- Business priority change
- Threat change
- Invalid assumption
- Measurement issue

## Output

- Executive summary
- What improved
- What did not improve
- Material risk changes
- Invalidated assumptions
- Lessons learned
- Continue / Change / Stop decisions
- H2 or next FY recommendations
