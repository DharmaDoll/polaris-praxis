# Prompt: Design Security Strategy

Current StateとBusiness Strategyを基に、次年度または中期Security Strategyを設計する。

## Mandatory Logic

各戦略テーマについて以下を明示する。

```text
Business Objective
→ Security Risk
→ Threat / Attack Path
→ Target State
→ Strategic Objective
→ Initiative
→ Metric
→ Evidence
→ Residual Risk
```

## Requirements

- 3〜7個程度のStrategic Themesに集約する。
- Control導入そのものをObjectiveにしない。
- ObjectiveはRisk OutcomeまたはBusiness Outcomeで表現する。
- Current StateとTarget Stateの差を示す。
- 優先順位とその理由を明示する。
- やらないこと / 後回しにすることも明示する。
- Budget / Headcount / Engineering Capacity等の制約が不明ならUnknownとして扱う。
- Framework mappingは最後に行う。

## Deliverables

- Strategy Summary
- Strategic Themes
- Current → Target State
- Priority Rationale
- Annual Objectives
- H1 / H2 breakdown
- Dependencies
- Risks and assumptions
- KPI / KRI
- Residual Risk
